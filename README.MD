# Echo: Tactical Ops

A voice-controlled tactical shooter game for blind and visually impaired players.

## About
Echo: Tactical Ops is a modern warfare simulation played entirely through voice commands and audio feedback. Take on the role of a special operations soldier tasked with breaching a hostile compound.

## How to Play
1. Open the game in Chrome or Edge (best voice recognition support)
2. Allow microphone access when prompted
3. Tap the screen and speak your commands
4. Listen to the atmospheric descriptions and make tactical decisions

## Voice Commands

### Mission Phase
- "stealth" or "quiet" - Attempt silent approach
- "breach" or "force" - Go in loud
- "status" - Check your health, ammo, and gear
- "gear" - Review your equipment

### Combat Phase
- "fire" or "shoot" - Engage the enemy
- "take cover" - Find protection
- "grenade" - Throw frag grenade
- "reload" - Reload your weapon
- "suppress" - Lay down suppressive fire
- "medkit" - Use medical supplies

## Features
- Rich atmospheric descriptions
- Tactical decision-making with consequences
- Resource management (ammo, grenades, medkits)
- Turn-based combat system
- Multiple approach paths
- Realistic modern warfare scenarios

## Requirements
- Modern web browser (Chrome/Edge recommended)
- Microphone access
- HTTPS connection (automatically handled by GitHub Pages)

## Accessibility
This game is designed to be fully playable without visual feedback. All game information is conveyed through speech synthesis.
